# TheNerdCollective.Brand.Dryk

DRYK plant-based brand pack for MudBlazor design tokens and responsive typography.

## Install

```xml
<PackageReference Include="TheNerdCollective.MudComponents.Shared" />
<PackageReference Include="TheNerdCollective.MudComponents.DesignTokens" />
<PackageReference Include="TheNerdCollective.Brand.Dryk" />
```

## Registration

```csharp
using TheNerdCollective.Brand.Dryk;

builder.Services.AddMudServices();
builder.Services.AddNerdDrykDesignSystem();
```
